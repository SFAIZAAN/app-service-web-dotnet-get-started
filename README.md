# ASP.NET sample for Azure App Service

This is an ASP.NET MVC web app that you can deploy to Azure App Service using Git. 

This code is the default MVC app as generated by 
[Visual Studio](https://www.visualstudio.com/products/visual-studio-community-vs).

To learn how to deploy this starter web app to App Service in a few minutes, go to 
[Get started with web apps in Azure App Service](https://azure.microsoft.com/en-us/documentation/articles/app-service-web-get-started/). 

## Run with Docker

This application targets .NET Framework 4.8 and runs on IIS, so it must use
Windows containers. In Docker Desktop, switch to Windows containers before
building. The Windows host must support Windows Server Core 2022 containers.

From the repository root, build and run the app:

```powershell
docker build -t sf-rental .
docker run --rm -d --name sf-rental-app -p 8080:80 sf-rental
```

Open [http://localhost:8080](http://localhost:8080). To stop the container:

```powershell
docker stop sf-rental-app
```

Rent records are currently held in memory by the application and are reset
when the container stops.
